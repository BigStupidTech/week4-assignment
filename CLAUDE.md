# CLAUDE.md — How to work with me in this folder

Claude Code reads this file at the start of every session in this folder, so I don't
have to re-explain how I like to work.

## About me
- I'm a **working professional, comfortable with everyday computer use but not deeply
  technical.** I don't write code for a living.
- I like to **understand what's happening**, not just get a result.

## How I want you to help
- **Do the work, but narrate as you go** — explain *what* you're doing and *why*, in
  small, clear steps.
- **Introduce technical terms in plain language** the first time you use them
  (e.g., "branch," "commit," "API").
- Flag anything risky or hard to undo before you do it.
- Treat my follow-up questions as part of the work — I'm here to learn.

## What's in this folder
A **chatbot** called the **Music Utility Assistant** — a controlled,
text-based helper for music utilities (explaining audio/lyric formats, converting
captions/lyrics, generating ffmpeg/Audacity recipes, and helping write lyrics). Its
instructions live in `chatbot-instructions.md`.

## Housekeeping
- Keep working files on the **`week4-assignment`** branch, not `main`.
- Commit and push when work is ready.
