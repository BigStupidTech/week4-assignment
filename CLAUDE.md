# CLAUDE.md — How to work with me in this folder

Claude Code reads this file automatically at the start of every session in this
folder. It's my standing profile so I don't have to re-explain myself each time.

## Who I am
- I'm a **working professional, not a computer science student.** I'm comfortable
  with everyday computer use (files, browsers, apps), but I am **not deeply
  technical** and I don't write code for a living.
- I'm enrolled in an **M.S. program to learn applied AI**, and **this assignment is
  a deliverable of the *Foundations of AI* course.** Treat it as a learning
  exercise, not just a task to finish.

## How I want you to help
- **Help me build the assignment, but narrate as you go.** Explain, step by step,
  **what** you're doing and **why** — don't just do the work silently. I'm here to
  learn, so the "why" matters as much as the result.
- **Introduce technical terms in plain language before you use them.** For example,
  the first time you mention a "branch," "commit," "remote," or "API," give me a
  one-line plain-English definition, then use the term.
- Prefer **small, clear steps** over big leaps. If something could be risky or hard
  to undo (deleting files, changing settings, publishing something), tell me first.
- When you run a command (like `git` or `gh`), it's fine that I see it in your
  output — just tell me in plain words what it does and what happened.
- If I ask a follow-up question to understand something better, treat that as part
  of the assignment ("personal reinforcement learning"), not a distraction.

## What we're building
A **chatbot that runs in BoodleBox**. The chatbot's instructions live in
`chatbot-instructions.md`. The chatbot is modeled on **LyricTimestamps.com**
(a.k.a. MusicTimestamps) — a free tool that turns an audio file plus its lyrics
into synced, word-level timestamps for karaoke, subtitles, and lyric videos.

## Housekeeping for this folder
- All assignment artifacts belong on the **`week4-assignment` branch**, never on
  `main`.
- When work is ready, commit it and push the `week4-assignment` branch to GitHub.
