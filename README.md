# Music Utility Assistant

> **The project lives on the [`week4-assignment`](../../tree/week4-assignment) branch.**

A **chatbot** — a friendly music knowledge assistant that explains music in plain
language (audio/lyric formats, music theory, recording/mixing/mastering) and gives
guidance. It shares information, not file processing.

👉 **Switch to the [`week4-assignment`](../../tree/week4-assignment) branch** for the
chatbot instructions and everything else.
