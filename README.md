# Music Utility Assistant

> **The project lives on the [`week4-assignment`](../../tree/week4-assignment) branch.**

A **chatbot** — a controlled, text-based assistant for music utilities:
explaining audio/lyric/subtitle concepts, converting captions and lyrics
(SRT ⇄ VTT ⇄ LRC), shifting timestamps, and generating `ffmpeg`/Audacity recipes.

👉 **Switch to the [`week4-assignment`](../../tree/week4-assignment) branch** for the
chatbot instructions and everything else.
